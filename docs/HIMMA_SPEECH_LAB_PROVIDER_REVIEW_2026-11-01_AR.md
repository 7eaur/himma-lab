# إقرار تحليل Azure بشكل مستقل عن نطق الطفل

**التاريخ:** 2026-11-01

## طلب المراجع
يحتاج مختبر الصوت خيارًا مباشرًا لتسجيل أن Azure حلّل التسجيل بشكل صحيح، أو أن تحليله غير صحيح، دون خلط ذلك بالحكم على نطق الطفل مقارنة بالهدف.

## نموذج التقييم
- مراجعة المزود `provider_feedback_verdict`: `accurate` / `inaccurate` / `unclear`.
- مراجعة نطق الطفل الأصلية `feedback_verdict`: `correct` / `incorrect` / `unclear`.
- لا يُفترض أن اعتماد مخرجات Azure يعني نجاح الطفل، ولا أن خطأ Azure يعني أن الطفل أخطأ.
- يمكن تسجيل تقييم واحد فقط أو كلا التقييمين في الطلب نفسه.
- يدعم المراجع تصحيح النص الذي قاله الطفل عندما كانت مخرجات Azure غير دقيقة، وحفظ ملاحظة مستقلة عن نتيجة المزود.
- أعمدة المزود الجديدة منفصلة، ولا يغيّر حفظها أي حقل قديم لتقييم الطفل أو الدليل الأصلي.
- الصفحات تُظهر نص Azure ودرجة Pronunciation Assessment عند وجودها، مع زر موافقة واضح.
- `academicEffect = none`؛ لا تغيير في سياسة المستويات أو الاعتماد.
- مسار البيانات: `POST /api/speech-test/feedback` ثم تحديث `public.speech_experiment_runs` مع ربط `id` وكود المشارك.

## التحقق
`npm run test:feedback-review` يشمل:
1. إقرار المزود وحده من دون محو حكم سابق على الطفل.
2. تقييم الطفل وحده دون محو إقرار المزود.
3. التقييمين معًا وتصحيح نص المزود.
4. رفض القيم غير المعروفة والطلب الفارغ والمدخلات غير الصالحة.
