# Himma brand asset source

The production logo shown in this repository must be sourced from the approved `Himma_Web_Logo_Kit_v1.0` package and follow `06_دليل_الهوية_البصرية_لمنصة_همة.pdf`.

Approved identity tokens used by the lab:
- Primary blue `#347FD9`
- Progress green `#51B985`
- Motivation yellow `#FFC857`
- Text navy `#20364D`
- Light background `#F7FBFF`
- Neutral border `#DCE8F2`

UI fonts: Tajawal, IBM Plex Sans Arabic, Noto Sans Arabic fallback stack.
